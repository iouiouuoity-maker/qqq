# QADAM — GitHub Pages сайты

Бұл — «Ойлан, дәлелде, шеш!» кітабының интерактивті нұсқасы. Сайтта QADAM-ның бес қадамы, 360 дәптерге арналған толық мысал, шешімдегі қатені табу, үш минуттық есеп сынағы және Cloudflare Workers AI арқылы істейтін қазақша көмекші бар.

## GitHub Pages-ке жариялау

1. GitHub-та жаңа бос репозиторий ашыңыз.
2. Осы бума ішіндегі файлдар мен `assets`, `js` бумаларын репозиторийдің түбіріне жүктеңіз. `index.html` түбірде тұруы керек.
3. Репозиторийден **Settings → Pages** тармағын ашыңыз.
4. **Deploy from a branch** таңдап, `main` тармағы мен `/(root)` орнын белгілеңіз.
5. Бет жарияланған соң Worker-ге жіберілетін сұраныстың Origin-і репозиторийдің GitHub Pages домені болады. Мысалы: `https://USERNAME.github.io`. `qadam-ai-worker/wrangler.jsonc` ішіндегі `ALLOWED_ORIGINS` мәнін осы доменге сай өзгертіңіз.

## AI-ды қосу

Worker-ді жариялағаннан кейін ғана оның нақты URL-і беріледі. Сол мекенжайды сайттағы **бір ғана** жерге енгізіңіз: `js/ai.js` файлының басындағы `AI_API_URL` мәні. URL пайдаланушы интерфейсінде көрсетілмейді және қолданушыдан ешқандай баптау сұралмайды. Бұл жол ауыстырылмаса, жаттығулар істей береді, ал AI көмекшісі қолжетімсіз екенін қысқа хабарлайды.

Worker-ді жариялау реті мен толық нұсқаулығы бөлек `qadam-ai-worker` бумасында.

## Мазмұн

- **QADAM әдісі:** Қара, Анықта, Дәлелде, Атқар, Мәнін тексер.
- **360 дәптер:** әр амалдың қандай шамадан алынғанын көрсететін қадамдық мысал.
- **Қате зертханасы:** қате шешімнің алғашқы бұрылған жері мен қатенің түрлері.
- **Ойлау журналы:** тәсілдерді салыстыру, қатені табу және көпқадамды есепті өзің жоспарлау; орындалғаны осы құрылғыда сақталады.
- **Үш минуттық сынақ:** таймер, жауапты бірден тексеру, дәлдік пен түсіндірме.
- **QADAM AI:** дайын жауапты төге салмайтын ишара, шешімді тексеру және қате талдау режимдері.

Телефон мен компьютер өлшемдеріне бейімделеді. Түс өзгерісін мәтін, белгі және орналасу да қолдайды.

## Кеңейтілген платформа

Сайтта 10 HTML бет бар: басты бет, оқу картасы, есептер банкі (12 есеп), қате зертханасы, жеке журнал, AI көмекші және 4 оқу тарауы. Барлық бумаларды, оның ішінде `lessons` бумасын бірге жүктеңіз. Журнал мен тарау белгілері осы браузерде сақталады; аккаунт арқылы басқа құрылғыға автоматты көшірілмейді. AI үшін бұрынғыдай бір ғана `js/ai.js` файлын баптау жеткілікті.
